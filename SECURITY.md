# Security

If you find a security problem in VinAura (for example SQL injection through a report's parameters, or a way
around the designer's access checks), please don't open a public issue. Report it privately with
GitHub's **Report a vulnerability** button, under the repository's *Security* tab.

Please include the version (the commit), what you did, and what happened. You'll get an answer as soon as possible.
The fix will be released before the problem is made public.
